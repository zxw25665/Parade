# network 模块说明

本目录是“游行”项目的网络层目录，设计上分为三部分：

- 发现面：节点发现与在线状态维护。
- 控制面：聊天与信令传输（设计端口 `4327`）。
- 数据面：文件分块传输（设计端口 `4328`）。

## 当前目录文件

- `discovery.go`：发现相关实现入口。
- `grpc_chat.go`：控制面（聊天/信令）实现入口。
- `grpc_file.go`：数据面（文件分块）实现入口。

## 设计目标（来自项目文档）

1. 局域网零配置发现（优先 mDNS，失败回退到遍历/口令）。
2. 标准消息与心跳走控制面长连接，保证低延迟与顺序一致性。
3. 大文件传输与聊天信令隔离，避免队头阻塞。
4. 所有对外网络数据统一经过加密封装。

## 与系统其他模块关系

- 与 `internal/core/crypto`：负责消息出站前加密、入站后解密。
- 与 `internal/core/eventbus`：发布节点上下线、消息接收、文件进度等事件。
- 与 `internal/app`：通过 `NetworkEngine` 接口被上层调用。

## 后续实现建议

建议按以下顺序落地：

1. 补齐 `proto/chat.proto` 与 `proto/file.proto`。
2. 完成控制面 gRPC 双向流（聊天、心跳、元数据同步）。
3. 完成数据面文件流式传输（按 offset 请求 + 分块传输）。
4. 接入真实发现机制（mDNS + 存活检测）。
5. 增加网络层单测与断线重连集成测试。
